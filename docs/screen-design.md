## 1. 画面一覧

本アプリの画面は全て1画面（アプリが1ページで完結する構成）。

| 画面               | 概要                             |
| ------------------ | -------------------------------- |
| メイン画面         | ボード（カラム＋カード）の表示   |
| カード作成モーダル | カード一覧の上に重ね表示（投影） |
| カード編集モーダル | カード一覧の上に重ね表示（投影） |

---

## 2. 画面遷移図

```
メイン画面
  │
  ├─ [+追加] クリック ──→ カード作成モーダル
  │                              │
  │                    [保存] ──→ メイン画面（カード追加）
  │                    [キャンセル / Esc] ──→ メイン画面
  │
  └─ カードの[編集] クリック ──→ カード編集モーダル
                                       │
                             [保存] ──→ メイン画面（カード更新）
                             [キャンセル / Esc] ──→ メイン画面
```
