## 6. アーキテクチャ概要

```
[ブラウザ]
    │  HTTP/JSON (REST API)
    ▼
[React 19 + TypeScript]  ← Vite 8 でビルド・開発サーバー起動
    │  /api/* → proxy → localhost:8080
    ▼
[Spring Boot 3.4.1 (Java 21)]  ← REST Controller → Service → Repository
    │  JDBC / JPA (Hibernate)
    ▼
[PostgreSQL 16]  ← Docker Compose でローカル起動（ポート 5433）
```
