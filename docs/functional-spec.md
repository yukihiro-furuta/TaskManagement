## 1. カラム（列）管理

- 「未着手」「作業中」「完了」の3列を固定で表示する
- 各列のカード数をリアルタイムで表示する

---

## 2. カード（タスク）管理

- カードを任意の列に新規作成できる
- 作成済みのカードを編集（内容修正）できる
- カードを削除できる
- カードを列間で移動できる（← → ボタン）
- カードをドラッグ＆ドロップで列内・列間の任意の位置へ自由に移動できる

---

## 2-1. 並び替え機能

カードの並び順は2種類の方法で変更できる。

| 方法 | 操作 | 動作 |
| ---- | ---- | ---- |
| ソート | カラムヘッダーの「優先度↓」ボタン | 高 → 中 → 低 の順に並び替える |
| ソート | カラムヘッダーの「期限↓」ボタン | 期限の近い順に並び替える（期限なしは最後） |
| フリー並び替え | カードをドラッグ＆ドロップ | 任意の位置へ挿入できる。列間移動も可能 |

- ソートはカラム単位で実行する（他のカラムには影響しない）
- 並び替え後の順序はローカルストレージに保存され、再読み込み後も維持される
- ドラッグ中は挿入位置を示す青いラインを表示する

---

## 3. 入力項目定義

カード作成・編集時に入力できる項目は以下のとおり。

| 項目     | 必須 / 任意 | 内容                 | バリデーション                   |
| -------- | ----------- | -------------------- | -------------------------------- |
| タイトル | 必須        | タスク名（テキスト） | 空文字不可・最大100文字          |
| 説明文   | 任意        | 詳細メモ（複数行可） | 最大500文字                      |
| 優先度   | 任意        | 高 / 中 / 低 の3段階 | 未選択の場合は「中」をデフォルト |
| 期限     | 任意        | 日付指定             | 過去日付も入力可能               |

---

## 4. 期限の表示ルール

期限の状態を色で視覚的に伝える。

| 状態     | 表示           | 色       |
| -------- | -------------- | -------- |
| 期限超過 | 期限超過 MM/DD | 赤       |
| 期限当日 | 今日           | オレンジ |
| 3日以内  | 📅 MM/DD       | 黄       |
| 4日以降  | 📅 MM/DD       | グレー   |

---

## 5. データ保存

- カードの追加・編集・削除・移動・並び替えをブラウザのローカルストレージに自動保存する
- ブラウザを閉じ・再起動してもデータおよび並び順が消えない
