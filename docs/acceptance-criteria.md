# 受け入れ条件

| -------------- | ------------ |
| ドキュメント名 | 受け入れ条件 |
| バージョン     | 1.1          |
| 作成者         | yukihiro     |

| 最終更新日     | 2026-10-25   |

---

受け入れ条件とは「この機能が正しく完成したと判断する基準」である。検収時に以下の確認を行う。

---

## 1. カード作成

| # | 確認内容                                                                     | 合否 |
| - | ---------------------------------------------------------------------------- | ---- |
| 1 | タイトルを入力して保存すると、対象カラムにカードが追加される                 |      |
| 2 | タイトルを空のまま保存しようとすると、エラーメッセージが表示され保存されない |      |
| 3 | ページを再読み込みしても追加したカードが表示される                           |      |

---

## 2. カード編集

| # | 確認内容                                                 | 合否 |
| - | -------------------------------------------------------- | ---- |
| 1 | 編集ボタンを押すと、既存の内容が入力済みのモーダルが開く |      |
| 2 | 内容を変更して保存すると、カードの表示が更新される       |      |

---

## 3. カード削除

| # | 確認内容                                               | 合否 |
| - | ------------------------------------------------------ | ---- |
| 1 | 削除ボタンを押すとカードがボードから消える             |      |
| 2 | ページを再読み込みしても削除したカードは表示されない   |      |

---

## 4. カード移動（ボタン）

| # | 確認内容                                                             | 合否 |
| - | -------------------------------------------------------------------- | ---- |
| 1 | 「→」ボタンを押すと、カードが右隣のカラムに移動する                 |      |
| 2 | 「←」ボタンを押すと、カードが左隣のカラムに移動する                 |      |
| 3 | 未着手カラムのカードには「←」ボタンが表示されない                   |      |
| 4 | 完了カラムのカードには「→」ボタンが表示されない                     |      |
| 5 | 各カラムのカード数表示がリアルタイムで更新される                     |      |

---

## 5. ドラッグ＆ドロップ

| # | 確認内容                                                             | 合否 |
| - | -------------------------------------------------------------------- | ---- |
| 1 | カードをドラッグすると半透明になり、掴んでいる状態が視覚的にわかる   |      |
| 2 | ドラッグ中に挿入位置を示す青いラインが表示される                     |      |
| 3 | カラム内でカードを任意の順序に並び替えられる                         |      |
| 4 | カードを別のカラムへドロップして移動できる                           |      |
| 5 | ドロップ後の並び順がページ再読み込み後も維持される                   |      |

---

## 6. 並び替え（ソート）

| # | 確認内容                                                             | 合否 |
| - | -------------------------------------------------------------------- | ---- |
| 1 | 「優先度↓」ボタンを押すと、そのカラムが高→中→低の順に並び替わる    |      |
| 2 | 「期限↓」ボタンを押すと、そのカラムが期限の近い順に並び替わる       |      |
| 3 | 期限なしのカードはソート後に最後尾に配置される                       |      |
| 4 | あるカラムをソートしても他のカラムの順序は変わらない                 |      |
| 5 | ソート後の順序がページ再読み込み後も維持される                       |      |

---

## 7. 期限表示

| # | 確認内容                                                       | 合否 |
| - | -------------------------------------------------------------- | ---- |
| 1 | 期限が過去日付のカードは赤色で「期限超過」と表示される         |      |
| 2 | 期限が当日のカードはオレンジで「今日」と表示される             |      |
