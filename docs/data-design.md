## 1. カードデータ項目定義

ローカルストレージに保存するデータの構造を定義する。

| フィールド名 | 型     | 必須 | 説明                              |
| ------------ | ------ | ---- | --------------------------------- |
| id           | 文字列 | 必須 | カード一意識別子（ランダム生成）  |
| title        | 文字列 | 必須 | タスク名                          |
| desc         | 文字列 | 任意 | 説明文（空文字も可）              |
| priority     | 文字列 | 必須 | `high` / `mid` / `low` のいずれか |
| due          | 文字列 | 任意 | `YYYY-MM-DD` 形式（空文字も可）   |

---

## 2. ストレージ構造

データは列ごとにカードの配列として保存する。

```json
{
  "todo":  [ { "id": "...", "title": "...", "desc": "", "priority": "mid", "due": "" } ],
  "doing": [ { "id": "...", "title": "...", "desc": "", "priority": "high", "due": "2026-12-31" } ],
  "done":  [ { "id": "...", "title": "...", "desc": "", "priority": "low", "due": "" } ]
}
```

---

## 3. ストレージキー

| キー               | 型     | 内容                     |
| ------------------ | ------ | ------------------------ |
| `kanban_todo`      | JSON配列 | 未着手カラムのカード一覧 |
| `kanban_doing`     | JSON配列 | 作業中カラムのカード一覧 |
| `kanban_done`      | JSON配列 | 完了カラムのカード一覧   |

---

## 4. 制約・注意事項

- ローカルストレージの容量上限は通常 **5MB**。大量データの登録は動作保証対象外
- ブラウザのキャッシュクリア・シークレットモードではデータが消える可能性がある
